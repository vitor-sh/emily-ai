# Segurança — versão em preparação

Não há release público aprovado neste pacote. Os módulos podem controlar arquivos, aplicativos, navegador, terminal e integrações remotas; execute testes em um perfil isolado.

Credenciais pertencem ao usuário. Não compartilhe `.env`, tokens, cookies, certificados, bancos de memória, logs ou histórico. O pacote público não deve ativar a ponte privada do autor.

Antes da publicação, os serviços remotos serão revisados para começar desabilitados e exigir autenticação quando habilitados. Essa revisão ainda está pendente; não exponha servidores deste rascunho à internet.

O canal privado de relatos será definido junto do repositório. Não publique uma vulnerabilidade acompanhada de credenciais ou dados pessoais em issues abertas.
